# Loess_Plateu
Loess Plateu plants biodiversity project
# simple_match.R 使用说明

学名名单 + 分布数据表 → 匹配 → 导出每个种的省级分布。

**匹配规则只有一条**：学名比对时只做去首尾空格、统一大小写，其余原样比较。
不做归并、不去重、不丢弃任何行，名单多少种进去就多少种出来。

## 用法

```bash
Rscript simple_match.R 名单.xlsx 分布表.xlsx
```

不传参数就用脚本顶部三个变量（`LIST_FILE`、`DIST_FILE`、`OUT_FILE`），改成自己的路径即可。
RStudio 里打开脚本改路径 → Source。

依赖：`readxl readr dplyr stringr writexl`（已安装）。

## 输入要求

- 名单：任意 Excel / CSV，有一个学名列（`学名`、`拉丁学名`、`species`、`taxon_name` 等自动识别）
- 分布表：Excel / CSV，有学名列 + 省份列（`Province`、`省`、`省份` 等自动识别）
- CSV 的 UTF-8 / GBK 编码都能读

## 输出

`省级分布_匹配结果.xlsx`，4 个 sheet：

| Sheet             | 内容                                            |
| ----------------- | ----------------------------------------------- |
| 01_匹配结果       | 名单原有全部列 + `记录数`、`省份数`、`省份列表` |
| 02_分布长表       | 学名 / 省份 / 记录数，一行一个种-省组合         |
| 03_名单未匹配     | 名单里在分布表中找不到的种                      |
| 04_分布表未用物种 | 分布表里有、名单没用到的种                      |

跑完控制台打印五个数，加减自洽：

```
名单不重复学名：4027
分布表不重复学名：4150
匹配上：3154｜名单未匹配：873｜分布表未用到：996
```

## 注意

- **`省份列表` 是分布表里的原生写法**，没做标准化。如果原始数据里既有"广西"又有"广西壮族自治区"，列表里两个都会出现。要统一的话另说。
- **`记录数` 是条数，不是省数**。分布表一行一个记录点时，记录数会远大于省份数。
- **原样匹配靠写法一致**。如果名单和分布表的学名写法不同（一边带命名人、一边不带，或者一边写变种），这些种会落到"03_名单未匹配"里，不会自动匹配上。
